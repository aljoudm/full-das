# Decisions of full-das (justification; reference draft for the report)

1. **Single parameter table.** `config/parameters_reviewed.tsv` (copy of the optimization table at f51b223, plus column `value_type` and rows added 22 Nov 2026). `run_optimization` reads it through `src/load_params_fd.m`, which drops the 10th column for the frozen loader (the frozen file stays unchanged). Why: one source for every number.
2. **Frozen copies in `third_party/`** with commits in `third_party/PROVENANCE.md`; the sources are never modified.
3. **Cold zone is not zero.** lambda_cold = 1 to 2 events/day for the whole zone (sensitivity 0.1 to 2); spread over cells by risk x length. Why: the Cold performance must be testable.
4. **Allocation = frozen MILP**, 22 real interdiction crossings (32 sites as a sensitivity); each solved case is saved in `results/` because the MATLAB licence is a trial.
5. **Profiling naming and use of height** (Yomna, 22 Nov): 0.4 m is a *channel spacing*; SNR is computed with her `detection_snr_db`, and the 12 dB threshold comes from simulation (the real value is measured in Phase 0); height is exploratory (+/- 8 cm), used only to exclude a match (difference >= `dh_reid_max` = 25 cm, parameter), never to identify or confirm a person. The primary claim of the DAS is stride length, speed and cadence.
6. **DASViT1D** accuracy (93.5 %, published) is for another device and site (Brno dataset); accuracy on FEBUS is unknown until tested on real data.
7. **Simulated Pd_DAS is a result next to the literature value** (user decision 22 Nov): the library gives 0.977 for intrusion types (`tests/test_stage4.m`) next to the literature Pd_DAS = 0.969 (`zeng2024`). The optimization keeps the literature value. The 0.977 depends on the ASSUMED amplitudes and the ASSUMED ground-coupling spread (log-normal, sigma 0.4): with a lower mean coupling or a larger spread it falls, so it must not replace Pd_DAS until it is calibrated on real recordings (Phase 0).
8. **Maps** show Esri World Imagery (attribution printed on every figure; the Esri terms for this use are still to be confirmed), the named places (Masjid al-Haram, Jamarat, Mina, Muzdalifah, Arafat), the five covered entrance checkpoints by name, a 10 km scale bar and a north arrow.
9. **Class "other"** (longboard, open/close, plus nothing else): kept as its own class in training; in the simulation it means "non-intrusion, no alarm". The report states how much of it is classified as a threat (user decision 22 Nov).
10. **Manipulation is a threat** (tampering with the fibre or the fence disables the monitoring system): merged with fence/impact into one class "climbing" = interaction with the fence or the fibre. Mapping to our classes: walking, running, vehicle, construction -> digging, fence + manipulation -> climbing, regular -> no_event, longboard + open/close -> other. Class animal has NO training data (PLACEHOLDER).
11. **Evaluation split** (Yomna + user): leave-one-recording-out, never random windows. The random-window accuracy is also computed to show how much it inflates the published 93.5 %. The split file of DASViT1D (`splits/split_indices.pkl`) is not used.
